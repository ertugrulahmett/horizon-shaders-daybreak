Daybreak 0.4.0 is Daybreak 0.3.0 for Horizon's shader API 0.2, which Horizon builds after the Nightly of 2026-11-13 require: they refuse API 0.1 packs, Daybreak 0.3 and older among them.

- **Linear light and HDR.** API 0.2 hands every stage linear colours. Daybreak keeps its look by lighting and grading in the same space as before, bloom is filtered and added in linear light, and highlights above white are kept for HDR displays. Ported by @Abeansits (#1).
- **Final API 0.2 inputs, no extra memory.** Daybreak draws terrain from `shaded_tint` and finds the water's surface by its normal, so it stays off the terrain look storage that reading `tint`, `shade`, `ao` or `face` turns on (a world reload when the pack starts and a third more terrain memory).
- Everything 0.3.0 brought: coloured light only where it is coloured (fewer stutters), screen-space water reflections, sharper and cheaper shadows.

On the Nightly of 2026-11-13 and older, stay on Daybreak 0.3.0.
