Daybreak 0.3.0 is about frame rate. Measured in a scripted flight through a town, a parade of mobs, fireworks, a redstone factory and a storm (7800X3D, RTX 4070 SUPER, 1080p), it scores 11 % more than 0.2.0, and most of what it saves is CPU time Horizon spent on the pack, not GPU time.

- **Coloured light only where it is coloured.** Torches, lanterns, fire, glowstone, lava and redstone lamps now take block light's own warm tint instead of a `[[lights]]` entry, so Horizon rebuilds its colour grid far less often: no more stutters by lamp walls and lava lakes. Soul fire, redstone torches, sea lanterns, amethyst, copper, froglights and end rods keep their colours. Redstone lamps are warm yellow now, like their texture.
- **Screen-space water reflections.** Water reflects what is on screen, and the sky where the screen ends, with no extra pass. The full water mirror, which also keeps Horizon from culling the world on the GPU, is still there as **Full mirror** on the Water page.
- **Sharper, cheaper shadows.** 1536 texels over 64 blocks by default (0.2: 2048 over 96), less than half the terrain for the shadow pass. Shadow detail and distance are new options with new values, so everyone starts on High; your other settings are kept.

Needs Horizon's shader API 0.1, which the Nightly of 2026-11-13 draws. Builds that serve only API 0.2 (Horizon's main since 2026-11-15) need Daybreak 0.4, which follows with the first Nightly that draws 0.2.
